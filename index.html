วิธีนำไฟล์นี้ไปเปิดเป็นเว็บจริงเพื่อแชร์ให้ลูกค้า (100% ฟรี)

แอปพลิเคชัน Bug.lifestyle นี้รวมโค้ด หน้าร้าน, ระบบอัปโหลดรูปภาพ, ตะกร้าสินค้า และแอดมินไว้ใน ไฟล์ index.html เดียว คุณสามารถนำไปโฮสติ้งเปิดใช้งานออนไลน์ได้ฟรีภายใน 1 นาที:

วิธีที่ 1: Netlify Drop (ง่ายที่สุด - ไม่ต้องสมัครบัตร)

  1. บันทึกไฟล์นี้ไว้ในเครื่องของคุณเป็นชื่อ index.html
  2. เข้าไปที่เว็บไซต์ app.netlify.com/drop
  3. ลากไฟล์ index.html วางลงในกล่องอัปโหลด
  4. คุณจะได้ลิงก์เว็บไซต์ออนไลน์ทันที เช่น https://bug-lifestyle.netlify.app สามารถส่งให้ลูกค้าช้อปปิ้งได้เลย!

วิธีที่ 2: GitHub Pages

  1. สร้าง Repository บน GitHub
  2. อัปโหลดไฟล์ index.html ขึ้นไป
  3. ไปที่ Settings > Pages > เลือก Branch main แล้วกด Save
